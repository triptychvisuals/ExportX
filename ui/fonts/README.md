# Fonts

Wix Madefor Display and Wix Madefor Text, designed by Dalton Maag for Wix and
released under the SIL Open Font License 1.1 (see `LICENSE-OFL.txt`). Latin
subsets only, taken from the `@fontsource/wix-madefor-display` and
`@fontsource/wix-madefor-text` npm packages (v5.3.0).

Bundled so the panel renders the same offline inside Resolve. See
`docs/DESIGN.md` for why this typeface.
